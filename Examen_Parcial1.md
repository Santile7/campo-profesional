## 1. Introducción al Área

Elegí el área de **Cloud Computing** porque hoy en día la mayoría de las páginas web y aplicaciones no se ejecutan en computadoras locales, sino en servidores en la nube que ofrecen empresas como Amazon o Google. Esta área se encarga de que los sistemas funcionen por internet, estén siempre disponibles y puedan crecer cuando muchas personas los usan al mismo tiempo.

---

## 2. Tecnologías Actuales

### 1. Docker
![Logo Docker](img/docker.png)

* **Uso principal:** Sirve para empaquetar una aplicación con todo lo necesario para que funcione (código, dependencias y librerías) en algo llamado contenedor. Esto ayuda a que el programa funcione exactamente igual en la computadora de cualquier programador o en el servidor.
* **Compañía / Vacante real:**
  * **Compañía:** Mercado Libre
  * **Vacante:** Desarrollador de Software / DevOps Junior ([Ver vacantes en Mercado Libre Careers](https://careers-meli.mercadolibre.com/))
* **Enlaces de referencia:**
  * [Sitio Oficial de Docker](https://www.docker.com/)
  * [Documentación básica de Docker](https://docs.docker.com/)

---

### 2. Kubernetes (K8s)
![Logo Kubernetes](img/kubernetes.png)

* **Uso principal:** Es una herramienta que ayuda a administrar muchos contenedores al mismo tiempo. Si una aplicación tiene mucho tráfico o si un contenedor falla, Kubernetes se encarga automáticamente de reiniciar el contenedor o abrir más para que la página no se caiga.
* **Compañía / Vacante real:**
  * **Compañía:** Spotify
  * **Vacante:** Ingeniero de Infraestructura / Backend ([Ver en LinkedIn Jobs](https://www.linkedin.com/jobs/search/?keywords=Kubernetes))
* **Enlaces de referencia:**
  * [Sitio Oficial de Kubernetes](https://kubernetes.io/)
  * [Documentación de Kubernetes](https://kubernetes.io/docs/home/)

---

### 3. Terraform
![Logo Terraform](img/terraform.png)

* **Uso principal:** Permite crear servidores, redes y bases de datos usando archivos de texto (código) en lugar de crearlos haciendo clic de forma manual en una página web. Esto hace que configurar infraestructura sea más rápido y con menos errores.
* **Compañía / Vacante real:**
  * **Compañía:** Globant / Softtek
  * **Vacante:** Administrador Cloud / Especialista en Automatización ([Ver en Computrabajo](https://www.computrabajo.com/))
* **Enlaces de referencia:**
  * [Sitio Oficial de Terraform](https://www.terraform.io/)
  * [Documentación de Terraform](https://developer.hashicorp.com/terraform/docs)

---

### 4. Amazon Web Services (AWS)
![Logo AWS](img/aws.png)

* **Uso principal:** Es la plataforma en la nube más utilizada del mundo. Ofrece servicios como computadoras virtuales (`EC2`), almacenamiento de archivos (`S3`) y bases de datos para que las empresas no tengan que comprar servidores físicos.
* **Compañía / Vacante real:**
  * **Compañía:** BBVA / Amazon
  * **Vacante:** Ingeniero Cloud Junior ([Ver en Indeed](https://www.indeed.com/))
* **Enlaces de referencia:**
  * [Sitio Oficial de AWS](https://aws.amazon.com/es/)
  * [Documentación de servicios AWS](https://aws.amazon.com/es/documentation/)

---

### 5. Google Cloud Platform (GCP)
![Logo GCP](img/gcp.png)

* **Uso principal:** Es la nube de Google. Proporciona herramientas de cómputo, almacenamiento y análisis de datos en los mismos centros de datos que utiliza Google para servicios como YouTube o su buscador.
* **Compañía / Vacante real:**
  * **Compañía:** Coppel / Google
  * **Vacante:** Desarrollador Cloud ([Ver en LinkedIn Jobs](https://www.linkedin.com/jobs/search/?keywords=Google%20Cloud))
* **Enlaces de referencia:**
  * [Sitio Oficial de Google Cloud](https://cloud.google.com/es)
  * [Documentación oficial de Google Cloud](https://cloud.google.com/docs?hl=es)

## 3. Resumen de las Tecnologías

| Tecnología | Tipo | ¿Para qué se usa? |
| :--- | :--- | :--- |
| **Docker** | Contenedores | Empaquetar aplicaciones para que corran igual en cualquier máquina |
| **Kubernetes** | Orquestación | Gestionar y balancear contenedores a gran escala |
| **Terraform** | Código de Infraestructura | Crear servidores y redes mediante archivos de configuración |
| **AWS** | Proveedor en la Nube | Rentar servicios de cómputo, almacenamiento y bases de datos |
| **Google Cloud** | Proveedor en la Nube | Alojar sistemas y trabajar con datos en la infraestructura de Google |
